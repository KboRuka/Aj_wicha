6. จุดสำคัญสำหรับสมาชิกในกลุ่มเตรียมอธิบายโค้ด (กรณีผู้สอนสุ่มถาม)
 * ทำไมไม่ใช้ .trim() กับรหัสผ่าน: เพราะ .trim() จะลบช่องว่างทั้งด้านหน้าและด้านหลังออก ทำให้ผิดโจทย์ข้อ 4 จึงต้องตัดออกเฉพาะ \r และ \n ที่เกิดจากการกด Enter
 * ทำไมต้องใช้ Array.from() (JS) และ .chars().count() (Rust): เพื่อให้นับจำนวนตัวอักษร Unicode (ภาษาไทย/อีโมจิ) ตามจำนวนตัวจริง ไม่ใช่นับตามขนาด Byte หรือ Code Unit
 * ทำไมโปรแกรมถึงรองรับรหัสผ่าน 64+ ตัวอักษรได้โดยไม่ตัดข้อความ: เพราะทั้ง String ใน JavaScript และ String ใน Rust จัดสรรหน่วยความจำแบบขยายขนาดอัตโนมัติ (Dynamic Heap Allocation) ไม่ได้จองขนาดตายตัว (Fixed Buffer) จึงเก็บข้อความยาวเกิน 64 ตัวอักษรได้ครบถ้วน
 * ส่วนไหนที่ป้องกันการพิมพ์ซ้ำและบันทึกไฟล์: ในโค้ดแสดงผลเฉพาะ username, charLength และข้อความผ่าน/ไม่ผ่าน ไม่มีการนำตัวแปร password มาแสดงผลซ้ำ และไม่มีการเ
